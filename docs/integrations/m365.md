# Microsoft 365 / Azure Integration

SIEMBA connects to Microsoft 365 and Azure AD using the Microsoft Graph API via an Azure App Registration.

## Step 1 — Register an App in Azure Portal

1. Go to https://portal.azure.com
2. Search for **App registrations** → click **New registration**
3. Name it `SIEMBA` → Supported account types: **Single tenant** → click **Register**
4. Copy the **Application (client) ID** and **Directory (tenant) ID** — you'll need these

## Step 2 — Create a Client Secret

1. In your app, go to **Certificates & secrets** → **New client secret**
2. Description: `SIEMBA` → Expires: 24 months → click **Add**
3. **Copy the secret value immediately** — it won't be shown again

## Step 3 — Grant API Permissions

1. Go to **API permissions** → **Add a permission** → **Microsoft Graph** → **Application permissions**
2. Add these permissions:
   - `AuditLog.Read.All`
   - `Directory.Read.All`
   - `SecurityEvents.Read.All`
   - `MailboxSettings.Read`
3. Click **Grant admin consent for [your org]** → confirm

## Step 4 — Configure in SIEMBA

1. Go to **Integrations** → click **Microsoft 365**
2. Fill in:
   - **Tenant ID** — from Step 1
   - **Client ID** — from Step 1
   - **Client Secret** — from Step 2
   - **Poll Interval** — how often to fetch logs (default: 300 seconds)
3. Click **Save Config** → **Test Connection**

A green status means SIEMBA successfully acquired a token and can read your audit logs.

## What Gets Collected

| Log Type | Events |
|----------|--------|
| Audit logs | User creation/deletion, role changes, MFA changes |
| Sign-in logs | Successful and failed logins, MFA prompts |
| Security alerts | Microsoft Defender alerts, risky users |
| SharePoint | File access, sharing, deletion |
| Exchange | Mail forwarding rules, delegation changes |

## Viewing M365 Data

- **SIEMBA Dashboard** → filter Source = m365
- **Kibana** → Index pattern `siemba-m365-*`
- **Grafana** → M365 dashboard
